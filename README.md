# Nectar

## Why?

I was reading a manga called `Shinju no Nectar` when this project started, so I just called it Nectar. Nothing special.

The problem: every time I connected a device, I had to open a new terminal and type `scrcpy -s <serial>`. I also had to keep track of which devices were already mirrored. It got annoying fast.

I don't trust random Chinese software on my machine, but I needed something lightweight to auto-poll ADB devices and launch scrcpy only for unmirrored ones.
